# Code of Conduct

## Our standard

line is an open-source project for developers building hands-free voice control
for local and remote AI agents. Project spaces should be practical, respectful,
and focused on making the software safer and easier to run.

Examples of behavior that helps the project:

- Give feedback that is specific, technical, and actionable.
- Assume contributors may be using different platforms, accessibility tools, and
  levels of experience.
- Respect maintainers' time by keeping issues reproducible and pull requests
  scoped.
- Discuss safety risks directly, especially where voice control can trigger
  agent actions in a real workspace.

Examples of behavior that is not acceptable:

- Harassment, insults, threats, or sustained personal attacks.
- Sexualized language or imagery in project spaces.
- Publishing private information without explicit permission.
- Dismissing security, privacy, or accessibility concerns without technical
  review.
- Using project channels for spam, unrelated promotion, or coordinated abuse.

## Scope

This Code of Conduct applies in project spaces, including GitHub issues, pull
requests, discussions, release comments, chat channels, events, and direct
project-related communication.

## Enforcement

Maintainers may remove comments, close issues, block accounts, or take other
reasonable steps when behavior harms the project or its contributors.

If you need to report conduct that should not be handled publicly, contact the
maintainer privately through the GitHub profile attached to this repository. For
security vulnerabilities, follow `SECURITY.md` instead.
